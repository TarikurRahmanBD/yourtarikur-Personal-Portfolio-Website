## ⚙️ Configuration

### Contact Form Setup

To enable the contact form, follow these steps:

#### Using Formspree (Recommended)

1. Go to [formspree.io](https://formspree.io/)
2. Sign up and create a new form
3. Copy your form endpoint
4. Update in `index.html`:

```html
<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">
  <input type="text" name="name" required>
  <input type="email" name="email" required>
  <textarea name="message" required></textarea>
  <button type="submit">Send Message</button>
</form>
```

#### Using EmailJS

1. Visit [emailjs.com](https://www.emailjs.com/)
2. Create a service and template
3. Update `js/form-handler.js`:

```javascript
emailjs.init('YOUR_PUBLIC_KEY');
const templateParams = {
  to_email: 'your-email@example.com',
  from_name: formData.name,
  message: formData.message
};
emailjs.send('YOUR_SERVICE_ID', 'YOUR_TEMPLATE_ID', templateParams);
```

## 🔧 Troubleshooting

### Issue 1: Styles Not Loading

**Problem:** CSS not applied, page looks plain  
**Solution:**
- Check file paths are correct (case-sensitive)
- Verify CSS files are in `css/` folder
- Check browser console for errors
- Clear browser cache (Ctrl+Shift+Delete)

### Issue 2: Images Not Displaying

**Problem:** Images show as broken  
**Solution:**
- Verify image path in `assets/images/`
- Check file name spelling (case-sensitive)
- Use relative paths: `assets/images/filename.jpg`
- Ensure image format is supported (JPG, PNG, WebP)

### Issue 3: JavaScript Not Working

**Problem:** Interactive features not functioning  
**Solution:**
- Check browser console for errors (F12)
- Verify JavaScript files loaded
- Check file paths in HTML
- Ensure JS files are in `js/` folder

### Issue 4: Responsive Design Issues

**Problem:** Layout breaks on certain screen sizes  
**Solution:**
- Test with DevTools device emulation
- Check media query breakpoints
- Verify viewport meta tag exists
- Clear cache and reload

### Issue 5: Form Not Submitting

**Problem:** Contact form doesn't send emails  
**Solution:**
- Verify Formspree/EmailJS setup
- Check form action URL
- Verify email configuration
- Test in different browser
- Check browser console for errors

### Issue 6: Mobile Menu Not Working

**Problem:** Hamburger menu not opening on mobile  
**Solution:**
- Check JavaScript is loaded
- Verify menu HTML structure
- Check z-index conflicts
- Test on actual mobile device

A: Use Git to commit changes: `git add .` → `git commit -m "message"` → `git push`
