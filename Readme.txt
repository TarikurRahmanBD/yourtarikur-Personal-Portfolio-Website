## 🚀 About the Project

This website is built as a personal hub to present my work as a **Graphic Designer, Animator, and Tech Enthusiast/Inventor**. Using a sleek side-navigation layout, it highlights key details about who I am, what I do, and how to get in touch with me.

### Key Sections:
*   **🏠 Home:** A captivating landing section with a dynamic typing effect introducing my roles.
*   **👤 About:** A brief overview of my professional background, education, and passions.
*   **📄 Resume:** A structured timeline of my education, experience, and key achievements.
*   **💼 Services:** The professional services I offer (Design, Animation, Robotics/IoT solutions, etc.).
*   **📬 Contact:** A functional contact form and social media links to get in touch.

---

## 🛠️ Built With

This portfolio is built using modern front-end technologies:

*   **HTML5 & CSS3** — For semantic structuring and beautiful, responsive styling.
*   **Bootstrap 5** — For a mobile-first, responsive grid system and pre-built components.
*   **Vanilla JavaScript** — For dynamic elements, typing animations, and smooth scrolling.
*   *Based on the iPortfolio Template by BootstrapMade.*
